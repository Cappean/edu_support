## 已发现并修复

- Windows 缺少时区数据库：显式加入 `tzdata`。
- 模型 SDK 分块内容：强制使用兼容的 Chat Completions 调用并统一最终文本。
- 学习进度分母原先取自已有学习记录：改为课程内容总数，并按视频去重完成数，补充考试成绩。
- 幂等表 `INSERT IGNORE` 的共享锁升级导致并发死锁：改为重复键更新直接获取排他锁，并发四次提交只创建一份申请。
- 服务重启遗留执行状态：通过检查点、租约、原 run ID 和业务幂等恢复。
- 快速切换学员时旧请求可能晚返回：使用界面版本号与中断信号阻止旧身份数据覆盖当前界面。
