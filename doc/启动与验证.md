# 启动与验证

## 环境

Python 3.12+、uv、Node 22+、pnpm 10、MySQL 8。数据库使用现有 `edu`，不要重复运行会删除重建数据库的 `reference/init_db.py`。

`reference/.env` 保存教育数据库连接配置，沿用本机已有配置。项目根目录 `.env` 配置真实模型，字段见 `.env.example`，三个模型字段均需填写。密钥不提交、不粘贴到日志。

## 安装

在项目根目录的 PowerShell 执行：

```powershell
$env:UV_CACHE_DIR = "$PWD\.runtime\uv-cache"
$env:UV_PROJECT_ENVIRONMENT = "$PWD\.runtime\venv"
uv sync
cd frontend
npm exec --yes --package=pnpm@10.28.2 -- pnpm install
cd ..
```

本环境原 `.venv` 的部分文件不可写，因此使用项目内 `.runtime/venv`。本地缓存同样放在 `.runtime`。该目录已排除版本管理。

## 运行

```powershell
.runtime\venv\Scripts\python.exe scripts/dev.py
```

- 学员客服：`http://127.0.0.1:5173`。
- 管理后台：`http://127.0.0.1:5173/admin`。
- 新应用 API：`http://127.0.0.1:8000/docs`。
- 教育后端：`http://127.0.0.1:8001`，仅供可信服务调用。

管理员账号为 `admin`。不设置 `ADMIN_PASSWORD` 时首次运行随机生成密码，保存在 `.runtime/admin-password.txt`，不在启动日志中显示密码。身份令牌有效期 12 小时。学员选择器是明确的演示能力，不作为生产登录方案。

Ctrl+C 结束启动脚本及其子进程。本项目演示版仅运行一个新应用实例，启动恢复租约最长等待 15 秒。前端开发代理转发 `/api`，不将教育服务凭据暴露到浏览器。

## 数据与兼容改动

教育后端首次启动只进行增量迁移：新增 `support_operation` 幂等记录表，将 `service_ticket.order_item_id` 放宽为可空以支持无订单问题。保留已有表和种子数据。

新应用消息、任务、知识、审计保存在 `.runtime/support.sqlite3`，LangGraph 检查点保存在 `.runtime/checkpoints.sqlite3`。初期采用 SQLite WAL 是单机演示的持久化适配器选择；独立于教育 MySQL，未来可替换。备份时停止应用后同时备份数据库和检查点，勿仅复制运行中的单个 SQLite 文件。

## 验证

```powershell
.runtime\venv\Scripts\python.exe scripts/check_model.py
.runtime\venv\Scripts\python.exe -m pytest -q --basetemp=.runtime/test-tmp
cd frontend
npm exec --yes --package=pnpm@10.28.2 -- pnpm build
```

完整后端测试（包含本机 MySQL）在根目录执行：

```powershell
$env:RUN_EDUCATION_INTEGRATION = "1"
.runtime\venv\Scripts\python.exe -m pytest -q --basetemp=.runtime/integration-tmp
```

浏览器验证在 `frontend` 下执行 `pnpm test:e2e`，默认使用本机 Microsoft Edge，运行前启动应用。安装了独立 Chromium 时可在 Playwright 配置中调整通道。`scripts/check_business_agent.py` 创建隔离测试业务记录并在结束时清理；`scripts/check_recovery.py` 需要先停止新应用端口 8000，仅保留 Reference 后端，它会自行启动、强制终止并重启新应用来验证恢复。

`check_model.py` 使用真实服务，检查结构化工具调用和流式响应，消耗少量模型用量。单元测试不把模拟响应冒充真实联调。更多场景的实际验收结果记录在开发进度中。

## 演示路径

选择预置学员 → 查询订单 → 插入课程或知识咨询 → 继续退款任务并补齐信息 → 查询申请状态。管理员审批后，学员查询结果。工单路径为提出具体问题并同意提交 → 管理员公开回复或内部备注 → 学员补充 → 管理员公开结单 → 学员查看结果。

演示退款不连接真实支付，不代表真实资金流转。管理员通过后以事务更新模拟支付、订单、报名和申请状态。Agent 不能审批退款。
